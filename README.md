# 🎓 Mathematicians Academy  

> **A Complete Educational Management Platform**  
> Empowering students, teachers, and parents with a seamless learning experience — both **online** and **in-center**.

---

## 🌟 Overview  
Mathematicians Academy is a **role-based education system** that supports interactive lessons, online exams, smart payment methods, and real-time communication between all stakeholders in the education process.

---

## 👥 User Roles  

### 🧑‍🎓 Student  
- 📋 **Register** with dynamic form based on grade level.  
- 🎥 Watch **interactive video lessons** after payment or attendance.  
- 📝 Submit homework, quizzes, and section work before deadlines.  
- 📅 Track everything with a **personal calendar**.  
- 🏆 Earn points for activities and redeem them for **free lessons**.  

---

### 🛡️ Admin  
- 🗄 Manage **all users** and **financial statistics**.  
- 🗂 Add, edit, or delete lessons, exams, and accounts.  
- 🔄 Transfer students or assistants between groups.  
- 🆓 Unlock lessons and assign points manually.  
- 📷 Record attendance (QR code or manual).  

---

### 👨‍🏫 Teacher  
- 🆕 Create lessons, exams, and prerequisites.  
- ❓ Add **in-video quiz questions**.  
- 🏢 Manage branches and revision lessons.  
- 📊 Track supervisor and assistant performance.  

---

### 👩‍💼 Supervisor  
- ✔ Approve or reject assistant grading.  
- ⏳ Approve requests for extensions or free lesson access.  
- 📈 Monitor assistants' **accuracy and performance**.  

---

### 🧑‍💻 Assistant  
- ✏ Grade homework and exams for assigned groups.  
- 📤 Send results to supervisors for review.  
- 📅 Request lesson extensions (needs supervisor approval).  
- 🏅 Receive performance evaluations.  

---

### 💰 Accountant  
- 💳 View all payment transactions.  
- ✅ Approve Vodafone Cash payments.  
- 🔑 Manage lesson access codes.  

---

### 👨‍👩‍👧 Parent  
- 📑 Receive **weekly and monthly performance reports**.  
- 👀 Track attendance (online & in-center).  

---

## 🚀 Key Features  

- 🆔 **Smart Student Registration** — Single form adapts to grade level.  
- 💳 **Multiple Payment Methods** — Lesson codes or Vodafone Cash.  
- 🎥 **Interactive Video Lessons** — Must pass in-video quizzes to proceed.  
- 📝 **Advanced Exams**:  
  - Fixed question sets.  
  - Randomized from question banks.  
- 🏆 **Point System** — Earn & redeem for free lessons.  
- 📅 **Full Calendar** — All deadlines & lesson expiry dates.  
- 📷 **In-Center Attendance** — QR or manual check-in.  
- 🔐 **Role-Based Permissions** — Secure and structured control.  

---

## 🛠 Tech Stack  

**Frontend**: React.js
**Backend**: Node.js (Express.js)  
**Database**: MongoDB 
**Real-time**: Socket.IO  
**Authentication**: JWT + Role-Based Access Control  
**Video Handling**: Plyr.js   
**Payment**: Vodafone Cash API + Code System
